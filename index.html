01

專案概述

專案目標

以現有 Claude Artifact 的架構與設計元素為基礎，建置一套可正式營運的銥晟科技官方網站，並內建後台管理系統（CMS）。

所有頁面資料——品牌資料、首頁橫幅、產品分類、產品項目、服務項目、最新消息、頁面內容——皆可在後台新增、編輯、刪除，不需修改程式碼即可維護網站內容。

與現有 Artifact 的差異

項目現有 Artifact目標系統
前台頁面單頁應用（HTML／JS）保留原架構與設計，正式上線
資料儲存Firestore（依賴 Claude 環境）自有資料庫（SQLite → 可升 PostgreSQL）
管理功能管理員模式（僅 Claude 內可用）獨立後台，需登入，頁面資料可 CRUD
消息內容3 則範例佔位後台可新增編輯，填入真實內容
LINE 連結未設定後台可設定
部署不可獨立部署Ubuntu + Nginx，正式網域上線

系統定位

小型企業形象＋產品目錄型網站。前台公開瀏覽、後台僅管理員可存取。初期單一管理員即可，保留多帳號擴充能力。

目標架構

使用者瀏覽器前台（公開）／ 後台（需登入）
↓ HTTPS 443
Nginx反向代理 · SSL 終止 · 靜態快取
↓
Node.js 應用伺服器Express ／ API 層：前台資料聚合（公開）＋ 後台管理（需 JWT 認證）
↓

前台公開資料與後台管理 API 分層，後台一律需登入認證後才可存取。

API 設計明細

公開 API（前台）

方法路徑用途
GET/api/site聚合回傳前台所需全部資料（品牌／hero／群組／分類／產品／服務／消息／頁面）
GET/api/posts最新消息列表（僅已發布）

後台 API（需登入）

方法路徑用途
POST/api/auth/login登入（回傳 Session Cookie）
POST/api/auth/logout登出
GET/api/me目前登入者
PUT/api/admin/brand更新品牌資料
PUT/api/admin/hero更新首頁橫幅
PUT/api/admin/prod-intro更新產品與服務說明
GET／POST／PUT／DELETE/api/admin/groups[/:id]群組 CRUD
GET／POST／PUT／DELETE/api/admin/categories[/:id]分類 CRUD
GET／POST／PUT／DELETE/api/admin/items[/:id]產品 CRUD
GET／POST／PUT／DELETE/api/admin/services[/:id]服務 CRUD
GET／POST／PUT／DELETE/api/admin/posts[/:id]消息 CRUD
PUT/api/admin/pages/:key頁面內容更新
GET/api/admin/activity-log操作紀錄查詢

資安要求

  • 密碼一律 bcrypt 雜湊，不存明文
  • 後台所有 API 驗證 Session，未登入回傳 401
  • 表單輸入做 XSS 跳脫與 SQL 參數化
  • Nginx 層：限速、隱藏版本、HTTPS 強制跳轉

驗收標準

  1. 前台全頁面可正常瀏覽，設計與原 Artifact 一致（色彩／字型／LOGO／影片／導覽）
